# Birthday Surprise Website

A romantic one-page birthday surprise website with:

- a `0 -> 28` animated loading intro
- candle and love-themed motion
- a Chengdu trip reveal
- a floating panda animation
- custom flight tickets inspired by the provided screenshots
- personalized name and love message
- an embedded song section

## Files

- `index.html` - page structure and content
- `styles.css` - layout, styling, and animations
- `script.js` - loading progress and scroll reveal behavior

## Preview Locally

If Python is available:

```bash
py -m http.server 4173
```

Then open:

```text
http://127.0.0.1:4173/
```

## Publish On GitHub Pages

1. Create a new GitHub repository.
2. Upload these files to the repository root.
3. In GitHub, open `Settings -> Pages`.
4. Under `Build and deployment`, choose:
   - `Source: Deploy from a branch`
   - `Branch: main`
   - `Folder: / (root)`
5. Save and wait a few minutes.
6. Your site will be available at:

```text
https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPOSITORY_NAME/
```
